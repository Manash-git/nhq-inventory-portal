1. Overview

We will take the project files from your computer and put them on the internet so anyone in your office can use them. The process has 3 simple parts:

  1. Supabase — Create a free online database to store your inventory data
  2. GitHub — Upload your project files to the cloud (like Google Drive for code)
  3. Netlify — Host your website for free and connect it to the database

After this, your portal will be live at a URL like https://your-site-name.netlify.app

⏱ Time required: 20-30 minutes. Cost: Free (all services have free plans).

2. What You Need Before Starting

  • A computer with internet connection
  • The project folder (Portal web project) saved on your desktop
  • A modern web browser (Chrome, Edge, or Firefox)
  • An email address you can access (for signing up to GitHub and Netlify)
✅ Already have a GitHub or Netlify account? You can skip the sign-up parts and jump directly to the relevant step.

3. Step 1: Set Up Supabase (Database)

Supabase is the free online database that stores all your products, activity logs, and user information. Follow these steps:

Step 1.1 — Create a Supabase Account

  1. Open your browser and go to https://supabase.com
  2. Click the "Start your project" or "Sign In" button at the top-right
  3. Click "Sign Up" and enter your email + password (or sign in with GitHub / Google)
  4. Check your email for a verification link and click it to verify your account

Step 1.2 — Create a New Project

  1. After logging in, you will see a "New project" button — click it
  2. Fill in the details:
    • Name: nhq-inventory (or any name you like)
    • Database Password: Create a strong password and write it down somewhere safe (you will need it later for backups)
    • Region: Choose Singapore or India (closest to Bangladesh for faster speed)
  3. Click "Create new project"
  4. Wait for 2-3 minutes while Supabase sets up your database (you will see a loading screen)
📝 Note: Make sure to remember or save the database password. You won't need it for normal use, but it's important for database backups.

Step 1.3 — Find Your API Keys

  1. Once the project is ready, look at the left sidebar and click "Project Settings" (gear icon)
  2. In the left menu, click "API"
  3. You will see two important pieces of information:
    • Project URL (looks like: https://xxxxxxxxxxxx.supabase.co)
    • anon public key (a long random string starting with eyJ...)
  4. Copy both of these and keep them handy — you will need them when deploying on Netlify
⚠️ Important: Copy the "anon public" key, NOT the "service_role" key. The service_role key is secret and should never be shared.

Step 1.4 — Run the Database Schema (Create Tables)

Now we need to create the tables (products, activity_logs) in your database.

  1. In the left sidebar, click "SQL Editor"
  2. Click the "New query" button
  3. Open the file supabase-schema.sql from the project folder (inside Portal web project). You can open it with Notepad.
  4. Copy the entire content of that file and paste it into the SQL Editor on Supabase
  5. Click the "Run" button (▶) — it will create all the tables, indexes, and triggers automatically
  6. You should see a green success message. If you see errors, copy the SQL and run again
✅ Done! Your database is now ready. Let's move to GitHub.

4. Step 2: Create a GitHub Account & Push Code

GitHub is like Google Drive for code. We will upload the project there so Netlify can read and deploy it.

Step 2.1 — Create a GitHub Account (if you don't have one)

  1. Go to https://github.com
  2. Click "Sign up" and enter your email, password, and a username
  3. Verify your email by clicking the link GitHub sends you
  4. Complete the simple setup questions (you can skip most of them)

Step 2.2 — Create a New Repository

  1. After logging in to GitHub, click the "+" icon in the top-right corner → "New repository"
  2. Give it a name: nhq-inventory-portal
  3. Keep it "Public" (or "Private" — both work fine with Netlify free plan)
  4. Do NOT check "Add a README file" or ".gitignore" or "license"
  5. Click "Create repository"

Step 2.3 — Download Git and Upload Your Code

If Git is not already installed on your computer:

  1. Go to https://git-scm.com/downloads
  2. Download and install Git for Windows (click "Next" on all screens — default options are fine)

Then, follow these steps to upload your code:

  1. Open the project folder on your desktop: Portal web project
  2. Delete the .env file if it exists (it contains secret keys — we will add them directly on Netlify later)
  3. Delete the node_modules folder (we don't upload this — Netlify will install it automatically)
  4. Right-click inside the folder (on empty space) and select "Git Bash Here" or "Open in Terminal"
  5. Type these commands one by one (press Enter after each line):
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/nhq-inventory-portal.git
git push -u origin main
📝 Note: Replace YOUR_USERNAME with your actual GitHub username. The URL is the same as what you see on your GitHub repository page.

When you run git push, GitHub will ask for your username and password. Use your GitHub username and a "Personal Access Token" as the password (not your regular password).

How to create a Personal Access Token:

  1. Go to https://github.com/doc/settings/tokens
  2. Click "Generate new token (classic)"
  3. Give it a name like "deploy-token"
  4. Check the box "repo" (Full control of private repositories)
  5. Scroll down and click "Generate token"
  6. Copy the token (it starts with ghp_...) and use it as your password when Git asks
✅ Done! Your code is now on GitHub. Refresh your repository page in the browser to see all the files.

5. Step 3: Deploy on Netlify

Netlify is the free hosting service that will run your website and make it accessible via a public URL.

Step 3.1 — Create a Netlify Account

  1. Go to https://netlify.com
  2. Click "Sign up" in the top-right corner
  3. Click "GitHub" to sign up with your GitHub account (easiest method)
  4. Authorize Netlify to access your GitHub — this lets Netlify see your repository

Step 3.2 — Connect Your Repository

  1. After logging in to Netlify, you will see a dashboard. Click the "Add new site" button → "Import an existing project"
  2. Click "GitHub" as the Git provider
  3. Netlify will ask for permission to access your repositories — click "Configure Netlify on GitHub" and select the repository nhq-inventory-portal
  4. Find and click on your nhq-inventory-portal repository

Step 3.3 — Configure Deployment Settings

On the configuration page, Netlify will auto-detect most settings. Verify these are correct:

  • Branch to deploy: main
  • Build command: npm run build (should be filled automatically)
  • Publish directory: dist (should be filled automatically)

Click "Deploy site" and wait for 1-2 minutes while Netlify builds your site.

🎉 Almost there! Your site is deployed but it's not connected to the database yet. Let's fix that next.

6. Step 4: Set Environment Variables (Connect to Database)

Environment variables are like secret settings that tell your portal how to connect to the Supabase database.

Step 4.1 — Add Your Supabase Keys to Netlify

  1. On Netlify, go to your site dashboard (you should be there after deployment)
  2. Click "Site configuration" (or the settings tab)
  3. In the left menu, click "Environment variables"
  4. Click "Add a variable" → "Add single variable" and add these two:
Variable Name Value (What to put) Where to get it
VITE_SUPABASE_URL https://xxxxxxxxxxxx.supabase.co Supabase → Project Settings → API → Project URL
VITE_SUPABASE_ANON_KEY eyJhbGciOiJIUzI1NiIsInR5cCI6Ik... (long string) Supabase → Project Settings → API → anon public key
  1. Click "Save" for each variable
⚠️ Important: Make sure there are no extra spaces around the values. Copy-paste exactly.

7. Step 5: Re-deploy & Verify

After adding the variables, we need to rebuild the site so it picks up the new settings.

Step 5.1 — Trigger a Re-deploy

  1. Go to "Deploy" tab in your Netlify site dashboard
  2. Click "Trigger deploy" → "Clear cache and deploy site"
  3. Wait for the build to finish (1-2 minutes). You will see "Published" in green when done.

Step 5.2 — Open Your Site

  1. Click the generated URL at the top of the deploy page (looks like https://random-name-12345.netlify.app)
  2. Your NHQ Inventory Portal should open!

Step 5.3 — Customize Your URL (Optional)

You can change the random Netlify URL to something nicer:

  1. Go to "Site configuration" → "Site details"
  2. Click "Change site name"
  3. Enter something like nhq-inventory (if available)
  4. Your new URL will be: https://nhq-inventory.netlify.app

To use your own domain (like inventory.nhqbd.com):

  1. Go to "Site configuration" → "Domain management"
  2. Click "Add custom domain" and follow the instructions
  3. You will need to update your domain's DNS settings (contact your IT team or domain provider for help)

8. How to Make Changes Later

If you need to update the portal (fix bugs, add features, etc.), here's the simple process:

Step 8.1 — Edit the Files

Open the project folder on your computer and make changes to the code (e.g., edit About.jsx to change the About page content).

Step 8.2 — Push Changes to GitHub

Right-click inside the project folder → "Git Bash Here" → Run:

git add .
git commit -m "Describe what you changed"
git push

Step 8.3 — Netlify Auto-Deploys

That's it! Netlify automatically detects the new code on GitHub and re-deploys your site within 1-2 minutes. No manual steps needed.

✅ Live in 2 minutes! Just refresh your portal URL to see the changes.

9. Troubleshooting (Common Problems)

Problem: White screen / Blank page after deployment

Cause: Environment variables not set or incorrect.

Fix: Go back to Step 4 and double-check that you added both VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY correctly in Netlify's environment variables. Then re-deploy.

Problem: "Failed to fetch" or "Network error" in the portal

Cause: Supabase database is not set up or not connected.

Fix:

  1. Go to Supabase → SQL Editor and run the supabase-schema.sql file again
  2. Make sure the environment variables in Netlify match exactly what's in Supabase → Settings → API

Problem: Login says "Invalid credentials"

Cause: The credentials are hardcoded in the project — this is by design for this internal tool.

Fix: Use the exact demo credentials mentioned in the login page:

  • Root: manash@nhqbd.com / Man&Mond71
  • Admin: admin / Man@321%
  • Guest: nhq / Nhq@321%

Problem: "Account locked" message

Cause: You entered wrong password 3 times.

Fix: Wait 10 minutes for the lock to expire. The login page shows a countdown timer.

Problem: "Email or token has expired" error when pushing to GitHub

Cause: Your Personal Access Token has expired.

Fix: Go to GitHub Settings → Tokens, generate a new token, and use it as the password.

Problem: Build fails on Netlify with red error

Cause: Usually a missing file or code error.

Fix:

  1. Click on the failed deploy to see the build log (the error message is usually at the bottom)
  2. If it says "npm ERR!" — there might be a missing package. Make sure node_modules is not in the .gitignore file
  3. Fix the error in your local code, then git add . && git commit -m "fix" && git push
  4. Netlify will automatically rebuild

Problem: Images not showing

Cause: We switched from image upload to image URL. The image URLs need to be publicly accessible.

Fix: When adding a product, provide a direct link to an image (e.g., from Google Drive, Imgur, or any public image hosting). Make sure the URL starts with https://.
