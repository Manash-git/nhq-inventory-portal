NHQ Inventory Portal - Deployment Guide

Step-by-step guide to deploy using Supabase + GitHub + Netlify

Step 1: Set up Supabase Database

1.1 Create a Supabase Project

Go to https://supabase.com and sign up / log in.

Click "New Project" and fill in:

  • Name: nhq-inventory
  • Database Password: Create a strong password (save it somewhere)
  • Region: Choose the closest region to you

Wait ~2 minutes for the database to be provisioned.

1.2 Run the Database Schema

In your Supabase project dashboard:

  1. Go to SQL Editor (left sidebar)
  2. Click "New Query"
  3. Open the file supabase-schema.sql from this project
  4. Copy the entire contents and paste into the SQL Editor
  5. Click "Run" (or press Ctrl+Enter)

This will create all 4 tables (users, products, activity_logs, sessions) plus the initial super user account.

1.3 Get Your API Keys

In your Supabase project:

  1. Go to Project Settings (gear icon) > API
  2. Copy the Project URL (looks like https://xxxxx.supabase.co)
  3. Copy the anon public key (starts with eyJ...)

Save these - you will need them in Step 3.

Step 2: Push Code to GitHub

2.1 Create a GitHub Repository

  1. Go to https://github.com and sign in
  2. Click the "+" icon (top right) > "New repository"
  3. Repository name: nhq-inventory-portal
  4. Keep it Public (or Private - both work)
  5. Click "Create repository"

2.2 Push Your Code

In your local project folder, open terminal/powershell and run:

git remote add origin https://github.com/YOUR_USERNAME/nhq-inventory-portal.git
git branch -M main
git add .
git commit -m "Initial commit"
git push -u origin main

Replace YOUR_USERNAME with your actual GitHub username.

Step 3: Deploy on Netlify

3.1 Connect Netlify to GitHub

  1. Go to https://app.netlify.com and sign up / log in
  2. Click "Add new site" > "Import an existing project"
  3. Click "GitHub" and authorize Netlify to access your repos
  4. Find and select "nhq-inventory-portal"

3.2 Configure Build Settings

The settings should auto-detect from netlify.toml. Verify they are:

  • Build command: npm run build
  • Publish directory: dist

Click "Show advanced" and scroll to "Environment variables".

3.3 Add Environment Variables

Add these two variables:

  • Key: VITE_SUPABASE_URL → Value: Your Supabase Project URL
  • Key: VITE_SUPABASE_ANON_KEY → Value: Your Supabase anon key

Click "Deploy site" (button at the bottom).

Important: After deployment, Netlify will give you a URL like https://random-name-12345.netlify.app. You can change this to a custom domain later under Site settings > Domain management.

Step 4: Auto-Deploy on Future Git Pushes

Netlify automatically deploys whenever you push to the main branch. To update the site:

git add .
git commit -m "Your change description"
git push origin main

Netlify will automatically rebuild and deploy within 1-2 minutes.

Step 5: Login Credentials

After deployment, go to your Netlify URL. Use these credentials:

  • Super User: manash / Password: Man@123

Log in as Super User first, then use Manage Users (from the user menu in top-right) to create Admin and Read-Only accounts.

Troubleshooting

Site shows blank page / Loading...

Check if environment variables are set correctly in Netlify. The app needs VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.

Login says "Invalid credentials"

Make sure you ran the SQL schema in Supabase SQL Editor. The seed user manash with password Man@123 must be inserted.

Database connection error

Check if your Supabase project allows connections from all IPs. Go to Supabase > Authentication > Settings > RLS - make sure policies are enabled.
